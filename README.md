# Blood Bank Management System
## Introduction
The Blood Bank Management System is a web-based application developed to manage blood donations and blood requests efficiently. The system helps maintain donor records, blood inventory, and request details in an organized manner. This project is designed to simplify the process of blood management and provide quick access to blood availability information.
# Objectives
* To manage blood donor information effectively.
* To maintain blood inventory records.
* To simplify blood request management.
* To reduce manual work in blood bank operations.
* To encourage blood donation awareness.
# Features
* Blood donor registration
* Blood request management
* Blood inventory tracking
* Donor list display
* Dynamic inventory updates
* Blood donation certificate generation
* Responsive and user-friendly interface

# Modules Description
## 1. Home Module
Displays the introduction and overview of the Blood Bank Management System.
## 2. Donate Blood Module
Allows users to:
* Enter donor details
* Select blood group
* Submit donation records
## 3. Request Blood Module
Allows users to:
* Request required blood type
* Check blood availability
* Update blood stock automatically
## 4. Inventory Module
Displays available blood quantity for each blood group.
## 5. Donor List Module
Shows registered donor details in tabular format.
## 6. Certificate Module
Generates a printable blood donation certificate for donors.
# How to Run the Project
